# 港区单车离线街机驾驶

项目根目录双击 **OpenRacing.cmd**，用已有 Godot 4.7.2 建立独立小工程并打开窗口。当前只驾驶，不计圈、不联网。

车会自动向前加速。A / ← 左转，D / → 右转；同时按两个方向先制动，停下后直线倒车，倒车限速为普通极速的四分之一。松开双键会逐渐恢复向前行驶。空格或屏幕任一“氮气”按钮触发同一个动作，R 复位并清空氮气，F2 实时调参，TAB 全景，ESC 退出；窗口失去焦点会暂停。

氮气初始为空，实际高速侧滑才能充能，最多三槽。每次点击消耗一槽、喷射 1.5 秒；再次点击追加时间，推力不叠加。已经激活的喷射不能取消；双方向仍能制动，但喷射结束前不能倒车。制动或实际后退时拒绝新喷射，不扣槽。左右屏幕氮气按钮共用资源，同时按住不重复消费；全部松开后再按才算下一次点击。

## 当前运动方式

默认采用新的“参考街机”起点：最大转向请求 175°/s、转向与松键时侧滑保留率均为 0.95、前进加速度 30 m/s²、普通极速 20 m/s，直线倒车上限 5 m/s。它借鉴用户提供的 TopDown 代码和参数截图，仍保留本项目的碰撞与氮气规则；不是已核实的 SkidStorm 原版参数。原交付的手感收到“基本感觉不到漂移”的反馈，新起点尚待用户试玩。

按 F2 打开右侧面板，五个滑条立即作用于下一物理步：转向速度、转向时侧滑保留率、松方向侧滑保留率、加速度、普通极速。上方显示实际速度、前/侧向速度、侧滑角和本步转向是否被碰撞限制。可切换“参考街机”和“原交付”，不重置动量或氮气；R 清空动量和氮气，但保留当前参数。参数只在当前窗口保留，重开恢复参考起点；面板向下滚动可见“复制当前参数”，便于贴到聊天反馈（实际系统剪贴板按钮尚未验收）。

**保留率越大越滑**：0.2 表示参考时间步内仅留下 20% 横向速度，通常更抓地；0.95 留下 95%，收尾更慢。这里以 50 Hz 作为换算基准，实际仍跑 60 Hz，用 `pow(keep, dt / 0.02)` 维持时间口径；截图没有给出 Unity 的真实时间步，所以 50 Hz 是明确选定的调参基准。试调时先只改一个数，例如比较 0.2 / 0.95 的抓地，再改松键保留率观察甩尾收尾。

新的 arcade_vehicle.gd 使用 60 Hz 平面运动：车头转向与世界惯性分开，持续转弯产生侧滑，松转向后逐渐恢复抓地。CharacterBody3D 每物理帧执行一次实际滑动碰撞；一个连续横向胶囊覆盖整个车身，碰撞后减速和沿墙滑动。旋转前做保守碰撞检查，贴墙时可能限制转向，可以倒车退开再转。

港区在这个入口使用平面变体，车的 Y 固定。车身倾斜、前轮转向与四轮滚动只是视觉，不运行悬挂射线；相机固定俯视角度跟位置，不跟着车头旋转。旧力式 vehicle.gd、旧坡道默认数据和测试源码仍保留作历史依据，当前入口已经改用街机版本。此原型不代表真实悬挂、跳跃、多人车辆碰撞或服务器接入。

## 环境、复验和隔离

本机引擎为 4.7.2.stable.steam.ed1daf0bf。默认路径 D:\SteamLibrary\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe；安装位置不同可运行 OpenRacing.cmd -Godot "<实际路径>"。没有自动下载、安装或修改全局配置。

OpenRacing.cmd -Mode Verify 会短暂打开窗口：新工程首次冷导入、十三脚本 --check-only、物理专项、实际窗口分别记退出码。首次冷导入失败不会以热导入掩盖。证据保存在主检出的 artifacts/racing-offline/，本轮轻量验收/恢复记录在 logs/racing-tuning-20261003/，旧记录在 logs/racing-arcade-20261003/；真实通过数量及未验范围见 [实时调参记录](../../../docs/17_framework_shooter_plan.md#racing-live-tuning-20261003)。

源码路径相对项目根；临时工作树也把运行输出放到主检出 F 盘。引擎采用 ._sc_，共享编辑器缓存留在 runtime/editor_data，每次项目 .godot、HOME/XDG/TEMP 都新建；不能称所有缓存全独立。入口一次只允许一个实例，收尾只处理自己创建的进程。街机 Play / Verify 分用途各最多两份，不挤掉旧力式专项的历史记录；清理失败如实保留。
