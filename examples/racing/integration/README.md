# 港区单车离线驾驶（阶段 1）

推荐在项目根目录双击 **OpenRacing.cmd**。它用本机已有 Godot 4.7.2 建立新的小工程，首次导入后打开驾驶窗口，不运行 RoomKit 服务。

操作：W/S 前进与倒车，A/D 转向，Shift 刹车，空格降低后轮抓地以漂移，R 复位，TAB 切换全景，ESC 退出。倒车先刹到接近静止再换向；漂移需要车速。当前不计圈、不计时、不连接服务器。

## 环境与隔离

现测 Windows 引擎为 `4.7.2.stable.steam.ed1daf0bf`，默认位置 `D:\SteamLibrary\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe`。安装位置不同可运行 `OpenRacing.cmd -Godot "<实际路径>"`；接受同提交的 4.7.2 stable steam/official 标识。没有自动下载、安装或改全局配置。

源文件使用项目相对路径。入口从 Git common directory 定位主检出目录；源码在工作树中时，输出仍统一到主检出的 `artifacts/racing-offline/`。复制引擎带 `._sc_`，编辑器数据在共享 `runtime/editor_data`；每次项目 `.godot`、HOME/XDG/TEMP 都新建，不能称编辑器缓存全部独立。引擎和缓存留 F 盘，一次只允许这个入口运行一个实例。

正常完成及失败运行登记到既有保留账本，Play / Verify 各最多两份，试玩不会挤掉已验收的 Verify；登记前后的路径、链接、进程、变化内容保护沿用 `tools/artifact_retention.ps1`。拒绝或未登记的旧目录不会自动接管、强删。2026-10-03 的 r1 删除被审批拒绝，所以三个运行目录暂存，未冒称全部清理完成。

## 车辆与物理

按文件范围接收驾驶候选 `591c09c`、街车 V2 `5a60db1`、港区 `0963332`；未合并这些候选的整条旧历史。车模四轮对应物理轴距 2.45 m、轮距 1.64 m、半径 0.34 m；物理原点为悬挂安装面，模型原点在地面，固定 Y 偏移 −0.67012 m。悬挂轮心、转向和转动在同一次物理回调更新；前轮上限 25°。车身使用两个凸盒，轮胎接地使用射线，不能声称轮胎侧面也有实体碰撞。

独立工程采用 GodotPhysics3D **600 Hz**，CCD 打开，最大物理步数 32。60 Hz 首轮在护栏首次接触前穿入约 7.9/19.3/5.4 cm；提高频率后，已测 6/8/12/25 m/s 的七种撞击保持在 5 cm 门槛内。600 Hz 是当前离线单车的取舍，未验 Linux 笔记本、八辆车或服务器成本。悬挂/轮胎仍使用力，正常驾驶不直接覆写速度；复位是唯一变换/速度重置路径。

港区约 458 m；独立赛道实际路面/坡道与护栏参与物理，无原型 Arena 大平面叠加。隐藏示意八车，保留发车格和路标。

## 实际验收

可复跑 `OpenRacing.cmd -Mode Verify`（会短暂打开真实窗口）。先做新工程冷导入，再做六脚本 `--check-only`，物理和窗口分开；任何阶段非零或 stderr/错误都失败，首轮冷导入失败不会补热导入抹掉。

最终 `stage1-r3`：冷导入/六解析退出 0，物理 **46/0**，窗口 **7/0**，均 stderr 0，入口退出 0。物理覆盖真实路面法向/承重、四轮对应、驱动/制动、坡道上坡过顶下坡和七种左右/斜撞/弯道/接缝/高速护栏撞击；每次真实物理帧都测，包含接触前帧、两个车体盒和全部实际接触邻段。护栏测量把车体面裁入真实有限护栏的 Y/Z 截面，不裁 X；几何反证保留真 8 cm 超限、左右符号、完全穿越、无原顶点的交点、相切和有限段远角。弯道旧无限面投影 9.05 cm 对应有限截面约 4.22 mm，旧失败未删除。

窗口只复验驱动/制动/复位、车轮和两视角截图，不重复全部碰撞专项。已查看真实 1280×800 截图；RTX 3080 的三秒行驶采样 360 帧、平均约 120 FPS、最慢 8.46 ms，只代表此短样本，非长时间/多车性能验收。

证据在主检出 `logs/racing-offline-20261003/` 和 `artifacts/racing-offline/stage1-r1|r2|r3/`。失败保留：r1 20/4；时序修正后 21/3；r2 脚本类型推断错误使物理阶段超时退出 −1；600 Hz 诊断 30/1；加测量控制时的旧复位接触混入 43/3。全部修正后的最终新工程才作为通过依据。
