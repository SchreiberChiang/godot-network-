# 港区单车离线街机驾驶

项目根目录双击 **OpenRacing.cmd**，用已有 Godot 4.7.2 建立独立小工程并打开窗口。当前只驾驶，不计圈、不联网。

车会自动向前加速。A / ← 左转，D / → 右转；同时按两个方向先制动，停下后直线倒车，倒车限速为普通极速的四分之一。松开双键会逐渐恢复向前行驶。空格或屏幕任一“氮气”按钮触发同一个动作，R 复位，TAB 全景，ESC 退出；窗口失去焦点会暂停。

氮气初始为空，实际高速侧滑才能充能，最多三槽。每次点击消耗一槽、喷射 1.5 秒；再次点击追加时间，推力不叠加。已经激活的喷射不能取消；双方向仍能制动，但喷射结束前不能倒车。制动或实际后退时拒绝新喷射，不扣槽。左右屏幕氮气按钮共用资源，同时按住不重复消费；全部松开后再按才算下一次点击。

## 当前运动方式

新的 arcade_vehicle.gd 使用 60 Hz 平面运动：车头转向与世界惯性分开，持续转弯产生侧滑，松转向后逐渐恢复抓地。CharacterBody3D 每物理帧执行一次实际滑动碰撞；一个连续横向胶囊覆盖整个车身，碰撞后减速和沿墙滑动。旋转前做保守碰撞检查，贴墙时可能限制转向，可以倒车退开再转。

港区在这个入口使用平面变体，车的 Y 固定。车身倾斜、前轮转向与四轮滚动只是视觉，不运行悬挂射线；相机固定俯视角度跟位置，不跟着车头旋转。旧力式 vehicle.gd、旧坡道默认数据和测试源码仍保留作历史依据，当前入口已经改用街机版本。此原型不代表真实悬挂、跳跃、多人车辆碰撞或服务器接入。

## 环境、复验和隔离

本机引擎为 4.7.2.stable.steam.ed1daf0bf。默认路径 D:\SteamLibrary\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe；安装位置不同可运行 OpenRacing.cmd -Godot "<实际路径>"。没有自动下载、安装或修改全局配置。

OpenRacing.cmd -Mode Verify 会短暂打开窗口：新工程首次冷导入、十一脚本 --check-only、物理专项、实际窗口分别记退出码。首次冷导入失败不会以热导入掩盖。证据保存在主检出的 artifacts/racing-offline/，轻量验收/恢复记录在 logs/racing-arcade-20261003/；真实通过数量及未验范围见 [阶段记录](../../../docs/17_framework_shooter_plan.md#racing-arcade-20261003)。

源码路径相对项目根；临时工作树也把运行输出放到主检出 F 盘。引擎采用 ._sc_，共享编辑器缓存留在 runtime/editor_data，每次项目 .godot、HOME/XDG/TEMP 都新建；不能称所有缓存全独立。入口一次只允许一个实例，收尾只处理自己创建的进程。街机 Play / Verify 分用途各最多两份，不挤掉旧力式专项的历史记录；清理失败如实保留。
