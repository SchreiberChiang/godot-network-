# 中文本机状态面板

> 早期入口：本文是 2026-09-21 早期无账号示例的只读面板（仓库根目录 `StartPanel.cmd`）。当前管理后台由 `StartManagement.cmd` 启动，见 [README](../README.md) 与 [docs/19](19_admin_ui.md)；0.5.0 框架独立包里同名的 `StartPanel.cmd` 打开的是新管理后台，不是本文的面板。

2026-09-21 用户要求类似宝塔的房间/玩家状态查看，本轮新增只读管理页面。仍只处理当前独立仓库，不访问旧项目，不增加 Node/Go 后端或公网部署。

## 打开

双击仓库根目录 **StartPanel.cmd**。它启动当前源码的示例宿主、两个取石子玩家窗口，并在默认浏览器打开面板。需要本机已配置的 Godot。`StartPanel.cmd -Game blocks` 切换为方块演示。再次运行入口会优先重开当前面板，不额外创建同一实例。

当时的0.1.0独立包内也有 **StartPanel.cmd**，使用包内正式EXE，不需要Godot编辑器。不要使用上轮旧包期待出现新面板；该包路径原记录在artifacts/delivery.json（2026-09-23已归档，见[文档归档](archive/README.md#证据位置)）。需要在Codex浏览器查看时可用`tools/panel.ps1 -NoBrowser`启动，再由本机私有描述文件提供一次性会话入口。

默认地址为本机127.0.0.1:28291。仅输入裸地址会显示缺少授权；入口脚本从当前用户私有run/panel-access.json读取随机访问凭据，通过URL片段传入，页面立即清除片段并仅存当前标签页sessionStorage，接口使用Authorization头。不要分享授权链接。宿主退出后移除描述文件，旧凭据失效。

这是本项目的宿主面板，不是任意系统服务探测器。默认示例有两间房，只有选定玩法启动两个玩家窗口。关闭两个游戏窗口后宿主回收并退出，面板显示离线；关闭浏览器本身不会结束游戏。运行时上限仍为30分钟。常驻无玩家服务器、远程登录以及网页创建/关闭房间均未在本轮实现。

## 可见数据

| 页面 | 真实数据来源 |
|---|---|
| 总览 | 当前宿主PID、运行时长、引擎版本、活动房间数、正式在线玩家数、大厅会话数、端口与隔离数 |
| 内存趋势 | Godot分配内存最近60个浏览器采样点；不是整机内存或CPU利用率。official模板未提供该指标时明确标注，不伪造0 |
| 房间 | RoomManager状态、游戏/房间ID、进程PID/UDP端口、已连接/预留人数、容量、心跳、实际工作集、失败原因；活动房间优先，最多128条 |
| 玩家 | 正式准入及正在预留/认证的玩家，稳定user_id、显示名、游戏与房间。点击房间可过滤成员，点击玩家可查看近期对局成绩 |
| 对局 | SQLite最近100条保存记录及单局玩家分数，每5秒异步读取；只投影允许字段，不公开任意游戏payload |

历史成绩不等于账号总资产。暂时没有真实账号资料、背包、商城、玩家IP/延迟、在线踢人、修改分数、任意SQL查询、系统CPU/磁盘统计。当前页面每2秒刷新；连接丢失会保留旧数据并明确标记离线，不能把旧值解读为当前状态。存储读取失败时也标记旧数据。

## 接口和边界

Godot宿主直接提供回环HTTP：GET /为固定HTML；GET /api/status需要随机Bearer授权。唯一响应契约为schemas/dashboard_status.schema.json，例子为examples/dashboard_status.example.json，面板API版本1，未修改现有游戏协议/SDK。错误状态401未授权、403错误Host/Origin、404未知路径、405非GET、400重复/非法头。无CORS授权、无文件浏览、无写接口。

请求最多4096字节，最多16个连接，单连接5秒，按部分写入发送响应。数据库查询使用独立线程和已有有界助手；面板关闭等待该工作完成。返回结构使用显式字段白名单，不能直接序列化RoomManager内部状态、席位或SQLite原始记录；不提供控制token、ticket/digest、证书私钥、数据库授权及私有路径。页面动态文字使用textContent，加载脚本/样式均在本地文件内，无第三方资源。

这是同一Windows用户下的本机操作界面，未提供跨用户/公网安全边界，不改防火墙。生产公网/远程面板需要另行设计部署和身份策略。

## 验证

`tools/run.ps1 -Mode panel`运行两个真实游戏和四个加密客户端，验证真实HTTP、Schema、四玩家观察、SQLite对局、授权拒绝、Host/Origin/路径/方法拒绝和关闭清理。`-Mode all`已加入panel。此专项包含原双玩法47项；不能把全部断言都算成新面板案例。

`tools/test_release.ps1 -Bundle <目录>`现通过-Panel -NoBrowser启动正式EXE自动测试；open_panel.ps1用真实授权请求核对宿主PID。浏览器验收另外记录在STATUS：实际布局、搜索、房间成员过滤、玩家详情和离线提示，不用HTTP状态码代替视觉验证。
