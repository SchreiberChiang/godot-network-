# RoomKit 横版射击 · 玩家客户端

这个目录可以直接运行：不需要安装 Godot，也不需要解压。

1. 双击 `StartGame.cmd`。
2. 第一次使用时，点“注册”，填入服务器主机给你的邀请码、用户名和密码；之后直接登录。
3. 在房间列表里选中一个房间，进入；也可以自己创建房间。A/D 移动，空格或 W 跳跃，鼠标瞄准射击。

目录里已经包含目标服务器的公开连接配置（`connection.json`）和证书（`server.crt`），不含账号数据、服务器私钥或管理员凭据。客户端版本必须与服务器一致；如果提示“客户端与服务器版本不匹配”，或者服务器地址变了，请让主机重新运行 `PreparePlayerClient.cmd`，把新目录整个发给你。`CheckClient.cmd` 可以检查文件是否完整。
